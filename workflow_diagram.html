Real-Time Multimodal Deepfake Detection Workflow

End-to-End Pipeline: Ingestion → Feature Modeling → Cross-Modal Fusion → Explainability

Stage 1 Input Ingestion & Decomposition

Mode A: File Upload

  • MP4 / WebM / MOV / AVI Container Ingestion
  • Uniform Temporal Sampling (12 Frames extracted across clip)
  • FFmpeg Audio Demuxing to 16 kHz Mono WAV

Mode B: Live Webcam Stream

  • Browser MediaRecorder streaming 2.5s rolling chunks
  • 6 Frames sampled per chunk for low-latency (<2s) inference
  • Microphone live stream audio synchronization
▼
Stage 2 Tri-Branch Feature Modeling

1. Visual Branch (ViT)

Spatial Artifacts
  • OpenCV Face Localization & 20% margin crop
  • Resized to 224x224 RGB Image Tensor
  • Vision Transformer (196 patch tokens self-attention)
  • Generates Visual Authenticity Score (S_v)

2. Audio Branch (Wav2Vec2)

Acoustic Artifacts
  • Wav2Vec2 Speech Transformer inference
  • Librosa 13 MFCCs & Pitch (F0) extraction
  • Spectral Flatness (vocoder noise check)
  • Generates Audio Authenticity Score (S_a)

3. Lip-Sync Branch

Cross-Modal Coherence
  • MediaPipe 478 3D Mesh (jawOpen blendshape)
  • Audio RMS Speech Energy Envelope extraction
  • Pearson Cross-Correlation (r) calculation
  • Generates Lip-Sync Score (S_s)
▼
Stage 3 Multimodal Fusion & Attribution

Dynamic Calibrated Decision Fusion combines scores while accounting for missing modalities (e.g. silent video):

S_authenticity = (0.45 × S_visual) + (0.35 × S_audio) + (0.20 × S_sync)
• If S_auth ≤ 0.42 → Likely Manipulated • If S_auth ≥ 0.60 → Likely Real • Identifies Dominant Factor (Visual, Audio, or Desync)
▼
Stage 4 Explainability & UI Presentation

Visual Explainability (Grad-CAM)

PyTorch backward hooks at vit.layernorm compute patch gradient weights, rendering a thermal Jet colormap directly over facial manipulation regions.

Lip-Sync Temporal Waveform

Interactive SVG chart visualizing Mouth Aperture curve vs Speech RMS Energy curve over time, graphically displaying viseme-phoneme sync or divergence.
